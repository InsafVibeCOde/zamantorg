# AGENTS.md

Правила проекта для ИИ-помощника. Следуй им при любой работе над кодом.

**Проект**: сайт компании ЗАМАНТОРГ — поставщик полиэтиленовых труб и трубопроводной арматуры (задвижки, фланцы, клапаны, люки, дождеприёмники). Страницы: главная, каталог (категории → виды → карточка товара), «О нас», форма заявки. Дизайн — «контрастный дуэт»: тёмные шапка/hero/блок заявки/подвал, светлые секции контента, оранжевый акцент (#ff8a00), плавные reveal-анимации при скролле (js/main.js + data-reveal).

## General Principles

- Чистый **HTML5 + CSS3** без фреймворков, библиотек и сборщиков (Bootstrap, Tailwind, npm — запрещены).
- Все стили — в отдельных файлах через `<link>` в `<head>`. Инлайновые `style="..."` и тег `<style>` запрещены (единственное исключение — критический CSS).
- Цвета и типографика — только через **CSS-переменные** из `:root` в `css/style.css`. Не хардкодить значения цветов внутри правил.

## Project Structure

- `index.html` — главная страница. Новые страницы (`catalog.html`, `about.html`, ...) кладутся в корень.
- `css/reset.css` и `css/style.css` подключаются в `<head>` именно в этом порядке.
- `images/`, `fonts/`, `js/` — создавать только при необходимости; лишние файлы не плодить.

## Code Standards

- Семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `footer` вместо простыней `div`.
- Доступность: `alt` у всех изображений, `aria`-атрибуты у интерактивных элементов, связанные `label` у форм.
- CSS по **BEM**: `.block__element--modifier`.
- Отступы — 2 пробела (HTML, CSS, JS). Логические блоки стилей разделять комментариями-заголовками.
- Изображения оптимизированы: WebP, сжатие, размеры по месту использования.

## Design Requirements

- **Mobile-first**: базовые стили для мобильных, улучшения через `@media (min-width: ...)`.
- Кроссбраузерность: Chrome, Firefox, Edge, Safari; где нужно — `-webkit-` префиксы.
- Контраст текста и фона — минимум **4.5 : 1** (WCAG AA); проверять перед добавлением каждого нового цвета.
- Шрифты — Google Fonts с фолбэками в `font-family`.

## Performance

- Минимум внешних запросов: никаких лишних шрифтов, библиотек, счётчиков.
- Изображения ниже первого экрана — `loading="lazy"`; для первого экрана — `fetchpriority="high"`.

## Verification

- Сборки и линтеров в проекте нет. Проверка ручная: открыть страницу в браузере (желательно через локальный статический сервер), убедиться в отсутствии ошибок в консоли, сверить мобильную и десктопную вёрстку.
- Для автоматизированных браузерных проверок подключены Playwright (`@playwright/test` в devDependencies) и MCP-сервер `playwright`. Это инструменты разработки — код сайта остаётся чистым HTML/CSS/JS без фреймворков.
- `node_modules/` не является частью сайта и не должен попадать в деплой или git без `.gitignore`.

## AI Workflow Rules

- Общайся с пользователем на русском языке.
- Перед созданием нового файла — объясни, зачем он нужен.
- После написания кода — предложи чек-лист ручной проверки.
- Предлагая изменения — поясняй, почему они нужны проекту.
- Работай пошагово по командам пользователя; масштабные изменения без запроса не начинать.
